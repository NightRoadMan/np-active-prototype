# НП+ Active: прототип с каруселью покупок

Интерактивный прототип экрана НП+ Active, 1:1 по макетам Figma и ТЗ (Confluence 4448288796).
Проект подготовлен для код-слоя в Figma Design (Code Layers).

## Запуск

```bash
npm install
npm run dev      # dev-сервер слушает $PORT (по умолчанию 5173)
npm run build    # сборка в dist/
```

## Как устроен

- `index.html` — разметка: панель настроек и экран телефона.
- `src/main.js` — состояние, правила сборки экрана и карусели.
- `src/style.css` — стили и токены.
- `public/img/` — картинки и иконки.

В узкой рамке (до 500 px, например кадр 402 × 874) экран занимает весь кадр без рамки телефона,
а панель настроек открывается кнопкой в правом верхнем углу.

## Импорт в Figma

В файле Figma Design нажмите **B**, затем **Clone remote repository** и вставьте адрес этого репозитория.
